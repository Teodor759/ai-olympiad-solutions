### This repo contains solutions to various AI olympiad-style problems.

Topics include: AI Search, Machine Learning (ML), Deep Learning (DL) and Reinforcement Learning (RL).

### Structure:

* `my-problems`: Problems created by me with multiple solutions and detailed explanaitions.
* `official-contests`: I consider official contests those that award prizes of any kind.
* `olympiads`: National olympiads from Romania, Kazakhstan, Serbia and Georgia.
* `practice-contests`: Contests that do not award prizes.
* `practice-problems`: Practice problems from the MLCompete platform.

### All the problems you see come from one of the following platforms:

* [Kaggle](https://www.kaggle.com/): (no description needed)

* [Nitro AI](https://judge.nitro-ai.org/): ROAI’s official platform. It also hosts stages for Kazakhstan, Serbia & Georgia NOAIs.  Most contests are hosted here.

* [MLCompete](https://platform.olimpiada-ai.ro/): ONIA’s official platform. It contains many practice problems but hosts fewer contests.
